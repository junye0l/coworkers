- 코드잇 스프린트 FE 18기 과정에서 진행한 심화 프로젝트
- 주제 선정 이유
  - 단순한 협업툴이 아닌 익명 게시판을 통한 팀원 모집이 가능한 매력적인 주제

  - 세세하고 다양한 구현사항이 있는 높은 난이도 프로젝트 도전
  <h2>사용기술</h2>

- Storybook

- prettier + husky
